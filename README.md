## 课堂流程

1. 选择或新建班级，再新建课程。默认推荐 10 词，可选 20、30、50，支持调整词库和难度。
2. 生成候选词单，搜索全部词库进行添加、删除、排序；确认后才生成正式课程。草稿、课程内容与打印题序持久保存。
3. 先打印随堂跟写纸。每行一个词或构词成分，保留姓名、年龄、时间，课后由老师收取。
4. 点击“开始讲课”：每个单词先读释义与双语例句，紧接一页“来源和构成”，再进入整组词的情景故事、互动翻卡、句子填空及完整回顾。
5. 多词大卡片支持中英双向翻转、独立揭晓、逐词标记掌握情况。句子练习可提交、保存结果。投影采用 16:9 单屏、键盘翻页、继续上次与可拖动的大字临时笔记。
6. 课后练习以单词之间的联系、句子填空为主，至少两张 A4；教师答案独立打印。网页直接预览和打印，可填写身份栏，填写值同步到各页。
7. 结课更新班级学习进度，之后随机选词可避开已学内容，到期词进入复习。删除课程或班级只移除课堂记录；独立词库、图片、音频继续复用。

资料按课程版本保存；修改素材会新建版本，旧例句、故事、练习和记录保留。当前进度为班级整体，尚未开发学生账号。未来只支持教师手动创建学生账号，学生仅能学习和查看分析报告。

## 已补全的示例课

《农场里的新同学》：`farm-friend-v2`，10 个 KET 单词保持原顺序，10 张词图、20 条主/补充例句、每词 2 组关联词与短例句、4 页连贯故事、4 道故事问答、82 段 AI 语音。生产迁移保留三个版本，当前课程编号 **WG-6B6FB513C5**。

单词为 afterwards、farm、online、matter、suit、song、classmate、photographer、lizard、stamp。词源引用可靠词典，区分词根、词基、前后缀、合成词、搭配和词形变化，不按相同字母强行拆词。

随堂练习 3 页，课后练习 4 页（构词联系 2 页、句子填空 2 页）；Safari A4 100% 打印预览已检查各页内容与分页。新课素材结构见 [word_study 规范](docs/word-study.md) 与 [素材工作流](assets/README.md)。

## 素材与语音

图片以写实、精美、有趣的生活场景为主，支持一词多图，无配图时留空。跨词故事遵循固定词单制作，短、自然、适合小学生；目标词之外尽量使用简单辅助词。所有素材、原始提示词、来源和 SHA-256 在 `assets/` 中追踪。

品牌图标结合风筝与打开的书，绿色和金色；`public/favicon.png` 为浏览器图标，`public/logo.png` 为独立品牌标志，网页使用原生中英文字标。源图与完整提示词在 [assets/brand/v1/](assets/brand/v1/prompts.md)。

语音为 Edge 英式女声 Sonia，慢速 10%，页面明确标记“AI 合成语音”。首次点击由 Worker 联网生成 MP3 并存入 R2；之后复用同一素材，支持句子、关联词、故事、问答和课前批量缓存。没有 GPT API 配音通道，也不会自动切回系统语音。Python `edge-tts` 仅用于本地素材制作；云端使用对应 WebSocket 协议实现。详情见 [语音说明](assets/audio/README.md)。

## 词表规模与材料覆盖

“约 1,500 个 KET 单词”是合理的常见教学规模，但按词头、短语、词形和英美变体统计，结果会不同。401 个是早期详解子集，不能代表 KET 的主要覆盖范围。

本版以剑桥 **2025 年 8 月词汇指南**限定范围，保留可用于课堂的词条，默认过滤最基础词。CSV 中的“条”包含部分短语、变体，不等于官方公布的独立单词数，也不宣称穷尽考试词汇。

| 本地 CSV | 总词条 | 默认过滤基础词 | 默认可选 | 例句 / 故事 / 练习覆盖 |
| --- | ---: | ---: | ---: | --- |
| `data/ket.csv` | 1,707 | 355 | **1,352** | 每一条都有 |
| `data/pet.csv` | 3,084 | 344 | **2,740** | 每一条都有 |
| `data/pet-extension.csv` | **1,454** | 已剔除 | **1,454** | 每一条都有 |

PET 与 KET 有 1,617 个相同拼写词条。PET 进阶表额外剔除了这些重叠词及基础词；它是 PET 的子集，启动时无需重复导入。

所有词条都预存了：

- 中文常用释义、词性、教学难度；
- 英文短例句、中文译句；
- 中文场景故事，其中英语部分使用目标词或已给出的短例句；
- 情境填空、答案和译句线索；
- 可用时提供构词关系、记忆提示和出处。

英语例句最多 16 个按空格分隔的词，尽量使用日常辅助词。**教学难度 1–3 是本工具的课堂分级，不是剑桥对每个词的官方标签。**低难度词也可以使用同样简短的句子练习；PET 的目标词较难，不刻意增加辅助词难度。

KET 有 935 条逐项编写或原教学子集的例句，772 条使用按词性和场景预制的句式；PET 对应为 1,527 / 1,557 条。记忆故事是配合例句编制的短情境模板，存在重复的叙事结构，并不是数千篇各不相同的文学故事。中文释义以常用义为主，来源包括教学修订及 ECDICT；这是可继续由教师维护的第一版教材，不是词典级全面义项审校。

PET 中 `base on`、`disappear`、`keep in`、`put through` 的自然例句有分离结构或词形变化，练习明确要求填词表原形，避免把不合语法的答案塞回句子。


## 词表维护与验证

KET/PET 种子 CSV 在课前生成并检查。CET-4/CET-6 保留导入入口，尚无内置词表。`study_json` 可携带结构化来源与构成；旧 CSV 的逐词故事列保留兼容，但讲课页面不再展示这些逐词故事。英语例句和构词来源须经人工/AI 制作时审校，课堂运行时不调用大模型。

```bash
npm run typecheck
npm run lint
npm test
npm run test:slides
npm run test:audio
npm run test:cloudflare
python3 scripts/lesson_assets.py validate
python3 scripts/lesson_audio.py validate

```

Python `storage.py` / `server.py` 保留为历史教材和 SQLite 迁移参考；旧发行包操作说明在 [legacy-offline-v1.md](docs/legacy-offline-v1.md)。当前产品的新增功能与正式验收使用 Cloudflare 本地模拟和生产环境。
