# 词芽课堂 · Word Garden

一个适合老师带班使用的本地单词课堂。先选班级，再生成课程；课堂内容、进度、例句、记忆故事和练习题都保存在本机。

## 打开使用

运行环境：**Python 3.9 或以上**。使用发布包不需要 Node.js、不需要安装 Python 依赖、不需要 API Key。

1. 解压 `WordGarden-v1.zip`，把整个文件夹放在可写的位置。
2. macOS 双击 **start.command**；Windows 双击 **start.bat**；Linux 运行 `bash start.sh`。
3. 浏览器会打开 **http://127.0.0.1:8765/**。保留启动窗口，关闭窗口或按 Ctrl+C 会停止服务。

如果电脑没有 Python，请先安装 Python 3.9+。也可以在项目目录运行：

~~~bash
python3 server.py
~~~

若端口被其他程序占用：

~~~bash
python3 server.py --port 8766
~~~

这是“本机网页 + 本机 SQLite”的方案，需要启动这个轻量本地服务；不通过 `file://` 双击 HTML 直接操作数据库。所有字体、页面资源、词库和教材都在发布包内，启动及日常课堂不依赖网络。朗读只使用系统已有的本地英语语音；没有语音时由老师领读。

## 大屏讲课模式

在课程右侧点击 **开始讲课**，即可进入横向 16:9 的课堂放映。页面会申请浏览器全屏；不支持全屏时使用铺满网页窗口的放映界面。侧边课程记录、备课设置、教师记录和打印答案都留在课程工作区。

- **逐页学习**：今天的任务 → 每个单词及例句 → 每个单词的场景故事 → 构词含义与来历 → 本课例词与例句 → 构词挑战 → 单词挑战 → 课堂回顾。
- **分步揭晓**：单词释义和练习答案初始隐藏。右方向键、PageDown 或空格先揭晓，再翻到下一页；左方向键或 PageUp 返回。也可以点击底部按钮。Esc 退出放映。
- **章节与目录**：顶部切换章节；底部“课程目录”可定位任意单词或故事。故事较长时分页，词根家族每页最多两个例词。
- **全课单词回顾**：最后一章完整展示本课全部单词、中文含义、英文例句和译文，补充例句也会显示。每页最多两个词条，长内容自动续页，保持大字；最后一页才显示“结束放映”。点击顶部“回顾”可直接进入。
- **临时笔记**：讲课左下角点击“临时笔记”，在大字窗口直接输入。拖动标题栏可以移动窗口，也可在标题栏聚焦后用方向键移动。翻页或关闭后重开会保留文字；退出本次讲课后清空，不写入课堂记录。打字时空格和方向键用于编辑，不会翻动课件；Esc 先关闭笔记窗口。
- **三种回忆方式**：每个单词练习页可切换“句子填空 / 看中文说英文 / 看英文说中文”。切换后重新隐藏答案，方便全班口头回答或在纸上书写。
- **继续上次**：未结课版本自动保存翻到哪一页，“继续第 N 页”从上次位置开始。“记住了 / 再练一次”保存本班课堂标记；放映结束后仍需在课程工作区结课。
- **旧课兼容**：已有课程也能放映，继续使用当时保存的单词、故事和习题；新教材不覆盖旧快照。已结课或旧版本放映用于复习，不修改原来的掌握标记。

界面直接面向学生提问、邀请表达。故事是帮助记忆的场景，构词来历单独说明并附词典来源，不把编写的情节当作历史词源。新增词缀来历依据 Merriam-Webster 的对应词条整理；详见 `data/root-stories.json`，如 [-ly](https://www.merriam-webster.com/dictionary/ly-)、[-ment](https://www.merriam-webster.com/dictionary/-ment)、[-able](https://www.merriam-webster.com/dictionary/able)。

本次另增 179 个级别词条的第二例句（KET 73 / PET 106，两个词表存在重叠），以及 29 个级别词条的独立场景故事（KET 12 / PET 17）。其余词条保留预制短例句和场景模板，全部素材仍在上课前编译到 CSV、本地导入，无需联网生成。新课使用材料版本 `2026-09-v2`。

## 一节课怎么用

1. **选择班级 / 新建班级**：每个班有独立的课程、已学词和到期复习记录。
2. **设置抽词范围**：选择 KET / PET、难度区间、单词数、学习目标，再点“生成候选词表”。随机抽词支持 5–100 个，提供 20、30、50 个快捷选项。
3. **确认词表**：查看单词、含义和例句，可删除、替换、上下调整顺序，或用英文 / 中文搜索全部已导入词库添加单词。手动选择可跨词表、难度和已学过滤条件，同一英文拼写不会重复添加。最终可保留 1–100 词；点击“确认并创建第 N 课”才会建立正式课程。词表草稿及每次编辑自动保存到 SQLite，刷新后进入同班“新建一课”即可继续。
4. **先打印**：确认成功后立即点“课前打印”，先印随堂跟写纸。此时无需先进行任何教学步骤。
5. **开始讲课**：点击右侧“开始讲课”进入大屏放映，按章节逐页学习。需要查阅时退出放映，使用课程页的四个步骤标签。
6. **词根和词汇**：从本课词汇汇总明确的词基、前后缀及合成成分，查看相关词与可核查的来历；可隐藏含义，让学生先解释。
7. **课堂互动练习**：中英双向翻卡、逐词标记“记住 / 再练”、情境拼写填空和构词口述挑战。拼写可存草稿、提交评分；每次提交结果都会保存。
8. **记录和结课**：保存课堂笔记，再结束本课。默认新课避开本班学过的词，到期词可在复习模式中重新抽取。

随机抽词时，同班正在进行的其他课程会占用其单词，避免重复备课；未确认的草稿不占用词汇。手动搜索仍可选择已学或进行中课程的词，搜索结果会标注其状态。同一个英文词跨 KET / PET 共享本班学习记录；不同班互不影响。以归一化英文拼写去重，英美变体及同义词不全部合并。

确认后的词表顺序用于课堂和随堂跟写；课后填空仍独立打乱题序并固定保存。混合词表课程会显示实际来源（如 KET + PET），每个词使用对应词条预存的例句、故事、构词信息和练习。预览后导入新词库不会悄悄改写已确认列表中的教材。

未结课时可以重新设置条件，预览并确认词表后生成**新版本**。确认之前当前版本仍保留；旧版本保留当时的词汇、例句、故事、练习顺序、构词分组、记录和结果。已结课或旧版本可回看、重新打印、追加复习答题记录，不会覆盖当时的课堂掌握记录。

课程生成及翻卡标记自动保存；**课堂笔记和未提交的拼写草稿请点保存**。退出或切换前先保存自己的编辑内容。

## 两类 A4 材料

| 材料 | 使用时间 | 内容 |
| --- | --- | --- |
| 随堂跟写 | 上课前打印，课堂边听边写，课后收走 | 每行一个单词，按长度提供 1–4 遍书写空格；随后是构词成分跟写和中文含义空格 |
| 课后巩固 | 课后发给学生 | 构词含义、用本课词举例、看英文写中文、看中文写英文 |
| 教师答案 | 老师批改使用 | 对应课后练习的固定题序和参考答案，独立打印 |

三种材料都有可手写的**姓名、年龄、时间**空栏，也能在打印预览里先填写。选择 A4 纵向，关闭浏览器自带页眉页脚。材料含独立打印样式，隐藏网页工具栏、重复表头并避免从行中间分页。长词组会合并书写格，避免挤在过窄的格子里；不同用法的同形词缀会标注类型。浏览器 Ctrl/Cmd+P 的系统预览可确认最终分页，也可以保存为 PDF。

姓名等打印输入框只影响这次打印，不作为学生档案保存。课后中文答案和构词开放题由老师判断；网页自动评分限于英文拼写。

## 词表规模与材料覆盖

“约 1,500 个 KET 单词”是合理的常见教学规模，但按词头、短语、词形和英美变体统计，结果会不同。401 个是早期详解子集，不能代表 KET 的主要覆盖范围。

本版以剑桥 **2025 年 8 月词汇指南**限定范围，保留可用于课堂的词条，默认过滤最基础词。CSV 中的“条”包含部分短语、变体，不等于官方公布的独立单词数，也不宣称穷尽考试词汇。

| 本地 CSV | 总词条 | 默认过滤基础词 | 默认可选 | 例句 / 故事 / 练习覆盖 |
| --- | ---: | ---: | ---: | --- |
| `data/ket.csv` | 1,707 | 355 | **1,352** | 每一条都有 |
| `data/pet.csv` | 3,084 | 344 | **2,740** | 每一条都有 |
| `data/pet-extension.csv` | **1,454** | 已剔除 | **1,454** | 每一条都有 |

PET 与 KET 有 1,617 个相同拼写词条。PET 进阶表额外剔除了这些重叠词及基础词；它是 PET 的子集，启动时无需重复导入。

所有词条都预存了：

- 中文常用释义、词性、教学难度；
- 英文短例句、中文译句；
- 中文场景故事，其中英语部分使用目标词或已给出的短例句；
- 情境填空、答案和译句线索；
- 可用时提供构词关系、记忆提示和出处。

英语例句最多 16 个按空格分隔的词，尽量使用日常辅助词。**教学难度 1–3 是本工具的课堂分级，不是剑桥对每个词的官方标签。**低难度词也可以使用同样简短的句子练习；PET 的目标词较难，不刻意增加辅助词难度。

KET 有 935 条逐项编写或原教学子集的例句，772 条使用按词性和场景预制的句式；PET 对应为 1,527 / 1,557 条。记忆故事是配合例句编制的短情境模板，存在重复的叙事结构，并不是数千篇各不相同的文学故事。中文释义以常用义为主，来源包括教学修订及 ECDICT；这是可继续由教师维护的第一版教材，不是词典级全面义项审校。

PET 中 `base on`、`disappear`、`keep in`、`put through` 的自然例句有分离结构或词形变化，练习明确要求填词表原形，避免把不合语法的答案塞回句子。

## 为什么这样组织教学

- **构词法与整体记忆并行**：KET 中不少高频词不能可靠地拆成拉丁词根。本版区分词基、前缀、后缀、合成成分，不把相同字母硬解释成同一词根。KET 有 291 条、PET 有 459 条明确构词关联；其余结合情境记忆。
- **一课学完不等于长期掌握**：建议新班先从 20–30 个词试起，观察课堂情况后调整到 50 个。通过主动回忆、拼写和后续复习巩固。
- **先理解，再回忆，再书写**：小故事提供画面，词基/词缀提供联系，遮挡与填空检验是否能独立想起来。
- **练习纸用途分开**：跟写用于课堂参与，课后填空用于考察，教师答案单独保留。
- **复习有记录**：结课时“记住”初始安排 3 天后复习，待巩固或未标记安排次日复习。再次记住后延长间隔，最长 30 天。这是可解释的第一版课堂建议，不是个体化记忆模型。

当前进度以**班级整体**记录，尚不包含学生账号、逐人分数档案、多设备同步。老师可以把班级里多数学生还不会的词标记为“再练”。

## 本地数据与备份

- 数据库：`data/classroom.sqlite3`。
- 首次启动自动导入 KET / PET 完整材料 CSV。以后启动按文件摘要检查变更，只更新词库；课程使用自己的内容快照。
- 页面右上角“备份”可下载所有班级、版本、词库、进度、笔记和答题记录的 SQLite 备份。
- 恢复：停止服务，把现有数据库另存一份，再将备份复制到 `data/classroom.sqlite3`，重新启动。
- 整个文件夹可以迁移到另一台装有 Python 的电脑；请保持 `data` 目录可写。
- 如果已备份的数据库要与旧教材一同保留，请同时备份 CSV。启动时改过的种子 CSV 会更新未来课程使用的词库，已有课程快照仍保留。
- CSV 导入是新增 / 更新，不会因为新文件省略某词就删除数据库中的旧词。

服务器只监听 `127.0.0.1`，不向局域网公开。浏览器刷新或清理缓存不会删除课堂数据。

## 修改或新增词库

在“词库”里下载 CSV，用支持 UTF-8 的表格软件编辑后，选择对应级别导入。CET-4 / CET-6 目前只有导入入口，不附带未经整理的空壳课程；导入后才可选择。

必填列：

| 列 | 含义 |
| --- | --- |
| `word`, `level` | 英文词条、KET / PET / CET-4 / CET-6 |
| `meaning_zh`, `pos`, `topic`, `difficulty` | 中文、词性、主题、整数 1–3 |
| `example`, `example_zh`, `story_zh` | 英文例句、译句、中文记忆故事 |
| `cloze`, `cloze_answer`, `cloze_zh` | 填空题、答案、中文线索 |

常用可选列：

- `cloze_type`：默认 `context`，题目必须含一个 `__________`，放回答案后应与例句完全一致；`headword` 表示根据情境写词表原形。
- `is_basic`：0 或 1。指定常见功能词（a、an、lot、many 等）仍会被基础过滤器识别。
- `accepted`：允许的英美变体或明确等价答案，以 `|` 分隔。
- `parts_json`：构词成分数组，每项包含 `text`、`kind`、`meaning`；`kind` 为 `root/prefix/suffix/compound`，可增加有来源的 `story`、`source`。
- `display_word`、`phonetic`、`story_title`、`student_prompt`、`materials_version`：显示拼写、音标、故事标题、学生互动提示、材料版本。旧 `teacher_prompt` 列仍可导入，但不在学生页面显示。
- `examples_json`：可选补充例句，格式为 `[{"en":"A second short sentence.","zh":"第二个简短例句。"}]`，最多 4 条，每个字段最多 240 字。放映时每页最多两个例句。

导入前会验证所有行；发现缺失素材、重复词条、非法构词数据、填空与答案不一致等问题时整批拒绝，不会只导入半个文件。

开发者可修改 `data/examples-*.txt`、`data/meaning-*.txt` 和 `data/example-families.json`、`data/story-scenes.txt`、`data/root-stories.json`，然后执行 `npm run materials`，一次性编译并保存完整素材。此步骤在备课前执行；上课生成课程只查本地库。若直接手工编辑完整 CSV，请直接导入或重启，不要再运行编译器覆盖自己的 CSV 修改。

## 开发与检查

发布包已包含 `out/`，直接启动即可。修改界面源码时才需要 Node.js 22.13+：

~~~bash
npm install
npm run build
python3 server.py
~~~

开发热更新需要分别运行两个终端：

~~~bash
python3 server.py --dev --no-browser
npm run dev -- --port 3000
~~~

检查与打包：

~~~bash
npm run typecheck
npm run lint -- --quiet
npm test
npm run build
npm run package
~~~

前端为 React / TypeScript，沿用 Sites 的 Vinext 静态导出结构和组件；后端只有 Python 标准库。生成课程、重新生成版本、答题和结课使用 SQLite 事务。测试使用临时数据库，覆盖班级隔离、并发去重、材料快照、固定题序、完整导入、备份恢复与本机接口边界。

发布包不包含开发依赖、实际课堂数据库、源参考 PDF 或联网生成服务。已做自动化功能和静态构建检查；大屏放映此前已在 Chrome 中完成 50 词 KET / PET 课程逐页边界检查，并验证 1920×1080、1366×768 显示、全屏、键盘控制、答案遮挡、标记、退出恢复与打印入口。本次新增检查覆盖词表预览、跨库添加 / 替换 / 删除 / 排序、草稿刷新恢复、确认后内容一致、完整大字回顾，以及笔记输入、拖动、关闭重开、翻页和窗口缩放。

## 内容依据与许可

- [Cambridge A2 Key 词汇指南](https://www.cambridgeenglish.org/images/506886-a2-key-2020-vocabulary-list.pdf)，2025 年 8 月版：用于限定 KET 范围。
- [Cambridge B1 Preliminary 词汇指南](https://www.cambridgeenglish.org/images/506887-b1-preliminary-vocabulary-list.pdf)，2025 年 8 月版：用于限定 PET 范围。
- [Cambridge 英语构词法说明](https://dictionary.cambridge.org/grammar/british-grammar/word-formation_2)：区分词缀派生、合成等构词方式。
- [Merriam-Webster -er](https://www.merriam-webster.com/dictionary/-er)、[-ful](https://www.merriam-webster.com/dictionary/-ful)、[-less](https://www.merriam-webster.com/dictionary/-less)、[-ness](https://www.merriam-webster.com/dictionary/-ness)、[un-](https://www.merriam-webster.com/dictionary/un-)、[re-](https://www.merriam-webster.com/dictionary/re-)：相应词缀的来历参考，具体来源也保存在构词条目中。
