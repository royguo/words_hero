# 学生练习与记忆记录

教师在 `/students?class=班级ID` 手动创建和编辑学生；没有自助注册。学生的 `/learn` 只显示本班学习任务与个人练习历史。老师首页的“班级进度”暂不实现。

## 词汇范围

读取 `lessons.active_version` 指向的版本，且该版本 `status=completed`，班级与课程均未删除。每个词按规范化英文拼写去重，同词采用最近结束课程的含义。仅在老师明确点击结课后开放；生成、预览、打印不开放。已结课课程可以生成新版本，旧快照只读，新版本再次结课前该课不贡献词汇。

当前练习的每个词保存来源版本；教师换版或删除课程时，下一次学生请求会检测变化，撤销不再适用的未完成练习。个人记忆和已完成历史不删除。重新加入同词时继续使用已有个人间隔。

## 两阶段状态机

初始状态和词表由 Worker 创建，前端使用共享状态机即时判题和显示动画；每阶段通过后提交该阶段的动作列表。Worker 从已保存状态重放所有动作，重新核算分数。后续题序使用相同状态生成的确定性打乱，保证失败重试后的题目也一致，不接受客户端替换问题或分数。每组默认 10 词（不足时用实际数量），中英文两列独立打乱。完全相同的中文标签不会放入同一组；暂未选中的词保留在待练列表中。

- 消消乐：一个英文与一个中文组成选择。正确则移除一对；错误则将涉及的两个完整单词各自的英文和中文都移除，并分别记错。整组移除完毕后，有错就重来本阶段，没有错误才进入判断题。
- 中英对决：每个词有英先/中先各一次题目，每个方向真假混合（仅 1 词时没有其他干扰词）。错误会给题干和候选词各记一次，若是同词只记一次。必须做完剩余题，之后重来阶段 2；不会退回阶段 1。
- 两阶段整轮通过才完成本组，过往重试错误仍参与复习安排。每题先在浏览器暂存，再显示短反馈动画，无需等网络；错误重试也不逐题提交。正常一组只有两次答题保存请求，分别位于阶段 1 和阶段 2 通过时。

未同步动作按学生 ID 放在浏览器 localStorage，不包含密码、姓名或手机号；同浏览器刷新后从服务端状态重放动作继续。主动返回/退出时保存未完成部分，极长练习每 1000 个动作也会保存一次，以控制请求大小。跨设备从最后同步的位置继续；浏览器不允许本地存储时明确提示刷新会回到最后同步处，不改回逐题网络请求。

批量请求 `POST /api/student/sessions/:id/actions` 携带 `{revision, request_id, actions}`。D1 原子批处理同时保存游戏状态与整批事件；完成时一并更新所有词的记忆状态。重放途中任何错误都拒绝整批。网络失败时保留原请求，可刷新恢复、原样重试；相同请求不会重复累计，复用 ID 改变内容会拒绝。服务端版本已更新则以新版本为准，不能覆盖其他设备的进度。同一学生至多一个进行中会话，旧页面的单个 `action` 仍兼容。学生身份由签名 Cookie 与数据库当前账号版本共同核验，API 不接受客户端传入的“已经通过”标记。

## 调度

实现集中在 `lib/student-game.ts` 的 `REVIEW_MINUTES` / `scheduleReview`，无需在 UI 里复制算法。

| 情况 | 下次安排 |
|---|---|
| 首次两阶段通过，期间未错 | 10 分钟后 |
| 到期复习全对 | 依次进入 1、3、7、14、30、60 天 |
| 本组期间出错，即使重试后通过 | 降低一级，5 分钟后复习 |
| 尚未到期主动加练且全对 | 记一组历史，保持原定时间与级别 |

选词先取逾期最久的词，再加入未练词。没有到期/新词时显示下次时间，可以主动“再练一组”。界面不显示伪精确的“记忆百分比”。个人历史使用自己的 `student_id` 保存；一个学生的错误不会改变另一个人的任务。

这是受遗忘和间隔练习研究启发的产品规则，不是声称人人具有相同参数的艾宾浩斯公式。经典遗忘曲线研究和复现使用特定材料与时间点；最合适的间隔还与目标保持时间有关。参考 [Murre & Dros (2015)](https://doi.org/10.1371/journal.pone.0120644)、[Cepeda 等 (2006)](https://pubmed.ncbi.nlm.nih.gov/16719566/)。后续可以根据真实个人记录调整这些参数。

## 语音、动画和数据

英文显示时自动播放已有 Edge/Sonia 录音，统一经 `/api/audio` 和 R2 缓存。学生只可请求本班已结课词/例句的语音。播放器复用经“开始一组”手势开启的音频元素；翻页、返回或下一次选词会取消旧队列和请求，下载迟到也不会播旧词。若浏览器阻止自动播放，显示“朗读”按钮提示，答题仍能继续。

成功/失败提示是 `lib/student-audio.ts` 中原创 Web Audio 短音，无第三方下载、授权或追踪依赖。卡片消失、抖动、翻页和完成撒花由 CSS 实现，遵守 `prefers-reduced-motion`，不阻塞操作保存。

`students`、`student_sessions`、`student_events`、`student_memory` 是课堂私人数据，只进 D1 和私密备份，浏览器仅暂存当前未同步答题；Git 只保存迁移、代码、教材和公共素材。账号默认格式 `YYYYMMDDNNN`，日期按 Asia/Shanghai，序号在全站该日期的最大编号上递增，至少三位，超过 999 后自然扩为四位。最大编号包含已移除账号；新一天从 001 开始。前端表格提供建议，保存时服务端重新分配并通过唯一约束/事务冲突重试处理并发。手动填写账号仍可用，旧账号不自动改名。初始密码为最终账号后六位，自定义密码保持原值。密码用 PBKDF2-SHA256、随机盐与 100000 次迭代保存。教师更改账号/密码、移除学生后会撤销旧会话。姓名/手机编辑不重置记忆。

验证：`npm run test:students` 测状态机、批量重放、本机恢复、账号日期/序号、双词判错、间隔与音频取消；`npm run test:cloudflare` 在独立临时 D1/R2 中执行真实 HTTP 流程，核对两阶段只有两条保存事件、整批拒绝、丢失回包后的幂等重试、并发账号分配、权限边界、删除和课程换版。
